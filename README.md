# PR3_Bykov_Sedikov_ISRPO

Практическая работа №3. API для магазина одежды.
Быков Денис и Седиков Артем (`crysis064`).

Проект написан на ASP.NET Core 8. База данных — SQLite. Есть товары, размеры, остатки, пользователи и заказы. Пароли сохраняются в виде хеша. Обычный пользователь может зарегистрироваться и сделать заказ. Менеджер может менять статус заказа, остаток и доступность товара.

Распределение задач:
Денис — база данных, товары, регистрация и вход.
Артем — заказы и проверка запросов в Postman.
Ветки: `tovary` и `zakazy`. Готовый код в `main`.

Для запуска открыть `PR3_Bykov_Sedikov_ISRPO.sln` в Visual Studio 2022 и выбрать профиль `http`. База `store.db` и два товара создаются при первом запуске. Swagger: `http://localhost:5167/swagger`.

Для проверки запросов менеджера нужно создать файл `PR3_Bykov_Sedikov_ISRPO/appsettings.Development.json`:

```json
{
  "Manager": {
    "Login": "manager",
    "Password": "свой_пароль"
  }
}
```

Этот файл не добавляется в Git. Логин менеджера создаётся при запуске, если его ещё нет в базе.

Запросы находятся в `PR3_Bykov_Sedikov_ISRPO.postman_collection.json`. В Postman сначала указать переменную `managerPassword`, затем выполнить запросы по порядку. Регистрация, вход, товары, поиск, заказы и запросы менеджера есть в коллекции.

Коллекция проверена через Newman: 12 запросов прошли без ошибок.
