# PR3_Bykov_Sedikov_ISRPO

Практическая работа №3. API для магазина одежды.
Быков Денис и Седиков Артем (`crysis064`).

Проект на ASP.NET Core 8 с базой SQLite. Есть товары, размеры, остатки, пользователи и заказы. Пароли хранятся в виде хеша.

Покупатель может зарегистрироваться, войти и сделать заказ. Товары можно посмотреть и найти по названию. Менеджер может менять статус заказа и остаток товара. Он также может убрать товар из продажи или вернуть его.

Денис отвечает за базу данных, товары, регистрацию и вход.
Артем отвечает за заказы и проверку запросов в Postman.
Есть ветки `tovary` и `zakazy`. Готовый проект находится в `main`.

Для запуска откройте `PR3_Bykov_Sedikov_ISRPO.sln` в Visual Studio 2022 и выберите профиль `http`. При первом запуске создаются база `store.db` и два товара. Swagger откроется в браузере.

Для запросов менеджера создайте файл `PR3_Bykov_Sedikov_ISRPO/appsettings.Development.json` с таким содержимым.

```json
{
  "Manager": {
    "Login": "manager",
    "Password": "свой_пароль"
  }
}
```

Этот файл не попадает в Git. При запуске программа добавит менеджера в базу, если такого логина ещё нет.

Запросы есть в файле `PR3_Bykov_Sedikov_ISRPO.postman_collection.json`. В Postman впишите пароль менеджера в переменную `managerPassword`. Потом запускайте запросы по порядку.

В Newman проверены 12 запросов, ошибок нет.
